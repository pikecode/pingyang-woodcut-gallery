> 文档版本：v2.0

---

## 1. 项目概述

平阳木版年画数字馆藏，将441MB 的馆方藏品 Word 文档转化为可交互的多端数字画廊。

**核心数据：**
- 55 件藏品，65 幅图像，10 件双联作品
- 4 类题材：戏曲（38件）、神祇（13件）、吉祥（3件）、故事（1件）
- 年代以清代为主（54件）
- 原始图片约 438 MB（JPEG/MPO/PNG/TIFF 混合）

**产品目标：**
使用者可以浏览、筛选、搜索 55 件藏品，查看每件作品的展示图像、年代、规格、馆藏信息、画面描述和离线语音导览。

## 4. 各端开发命令

```bash
# Desktop（当前主项目，需要 Rust）
cd desktop && npm run dev         # 浏览器 UI，http://127.0.0.1:1420
cd desktop && npm run tauri dev   # 启动桌面窗口（热更新）
cd desktop && npm run tauri build # 打包 .dmg / .exe
cd desktop && npm run test:ui     # Desktop UI 自动验证

# 数据处理
python3 scripts/import_gallery.py   # 从 Word 重新生成数据库
cd desktop && npm run assets         # 生成 desktop/public WebP + JSON
```

> `h5/` 与 `miniapp/` 当前只保留历史实现，不纳入本阶段开发和验收范围。

> **注意**：桌面端需要 Rust 工具链。安装：
> ```bash
> curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
> ```
