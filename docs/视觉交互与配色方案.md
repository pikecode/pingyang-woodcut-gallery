# 平阳木版年画数字画廊：视觉交互与配色方案

> 文档版本：v1.0  
> 整理日期：2026-07-22  
> 适用范围：前端 UI 设计与组件开发参考

---

## 1. 设计理念

### 1.1 核心定位

本项目是以馆藏为核心的数字化图录，不是营销落地页。视觉语言服务于作品本身，而非抢夺注意力。设计参照坐标是印刷图录、博物馆陈列系统和档案数据库，而不是电商平台或媒体网站。

### 1.2 三条基本原则

- **作品优先**：版面让位于图像，文字和 UI 控件退到辅助位置。
- **克制而非装饰**：不使用渐变、投影叠加、装饰性几何或大圆角。视觉重量来自比例和留白，不来自视觉效果。
- **密度可控**：图录场景下用户需要扫描和比较，布局应支持高密度浏览，而非单件作品的沉浸展示。

## 2. 色彩系统

### 2.1 基础色板

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#f3f3ef` | 页面底色，带轻微暖调仿宣纸感 |
| `--white` | `#ffffff` | 组件内底色（卡片、面板、表单） |
| `--ink` | `#171714` | 主文字、激活态边框 |
| `--muted` | `#686861` | 辅助文字、标签、占位符 |
| `--line` | `#d4d3cb` | 分割线、普通边框 |

这五个 token 构成界面的中性骨架，覆盖 80% 以上的 UI 色彩使用。

### 2.2 功能强调色

| Token | 色值 | 来源参考 | 用途 |
|---|---|---|---|
| `--red` | `#b72e28` | 年画朱砂色 | 主操作、激活态、品牌标识 |
| `--green` | `#27675a` | 年画石绿色 | 次级信息、辅助状态 |
| `--gold` | `#ae8030` | 年画金泥色 | 引导标签、荣誉标注 |

强调色应谨慎使用：每个视口内同时出现的强调色面积应控制在总可视区域 **5%** 以内。三种强调色在同一区块内最多同时出现一种。

### 2.3 暗色区域

| 用途 | 色值 |
|---|---|
| 深底栏（馆藏概览） | `#1d2c28`（墨绿黑） |
| 页脚 | `#171714`（近黑） |
| 模态背景遮罩 | `rgba(10, 10, 9, 0.82)` |
| 英雄区文字遮罩 | `rgba(18, 18, 16, 0.82–0.86)` |

暗色区域内正文统一 `#ffffff`，辅助文字使用 `#bccbc6`（暖灰）。

### 2.4 配色禁区

- 不使用装饰目的的 CSS 渐变（`linear-gradient` / `radial-gradient`）。
- 不使用饱和度高于 60% 的颜色作为大面积背景色块。
- 不在图片上叠加半透明彩色蒙层。
- 暗色区域内不使用 `--red`（对比度不足），可以用 `--gold` 替代强调色角色。

## 3. 字体排版

### 3.1 字体栈

| 用途 | CSS 变量 | 字体序列 |
|---|---|---|
| 展示标题（题名、章节标题） | `var(--display)` | `"Songti SC"`, `"STSong"`, `"SimSun"`, serif |
| 正文与 UI 操作文字 | 继承 body | `"PingFang SC"`, `"Microsoft YaHei"`, sans-serif |

宋体用于展示层（大尺寸标题、作品题名），黑体用于交互层（按钮、标签、筛选控件）。两种字体气质上形成主次分工，不应混用。

### 3.2 字号比例

| 用途 | 桌面 | 移动 |
|---|---|---|
| 英雄主标题 | 86px | 48px |
| 页面大标题（H1/H2） | 48–58px | 38–44px |
| 弹层作品题名 | 43px | 36px |
| 网格卡片题名 | 26px | 24px |
| 列表行题名 | 31px | 22px |
| 正文描述 | 16–17px | 15px |
| 分类标签 / kicker | 11–12px | 11–12px |
| 元数据 / 注记 | 10–12px | 10–12px |

### 3.3 行高规范

| 文字类型 | 行高 |
|---|---|
| 大标题（> 40px） | 1.06–1.2 |
| 正文段落 | 1.75–2.0 |
| 说明文字（长段） | 1.7–1.8 |
| 标签 / 单行显示 | 不额外设置（依赖容器对齐） |

## 4. 间距与网格

### 4.1 页面容器

- 内容区最大宽度：`1240px`；Header 区：`1360px`。
- 两侧安全边距：桌面 `32px`，移动 `18px`。
- 公式：`width: min(1240px, calc(100% - 64px))`。

### 4.2 响应式断点

| 断点 | 宽度 | 主要变化 |
|---|---|---|
| 桌面 | > 1040px | 三栏卡片网格、全宽英雄左侧文字栏 |
| 平板 | 760px–1040px | 两栏卡片网格、部分控件隐藏（排序选择器） |
| 手机 | < 760px | 单栏、移动导航抽屉、弹层底栏弹出式 |

### 4.3 间距参考值

| 语义 | 参考值 | 典型用途 |
|---|---|---|
| 极小 | 6–8px | 图标与文字间距、badge 内边距 |
| 小 | 12–17px | 卡片内部间距、字段间距 |
| 中 | 24–34px | 卡片间距、弹层内边距 |
| 大 | 42–54px | 区块内竖向节奏、Section 内 padding |
| 超大 | 84–126px | 页面区块之间的 padding-block |

## 5. 圆角与边框

- 组件圆角统一限制在 **2px**，不超过 4px。
- 品牌印章、编号角标保持直角（0px）。
- 普通边框：`1px solid var(--line)`。
- 激活 / 焦点边框：`1px solid var(--ink)`。
- 焦点轮廓：`outline: 2px solid rgba(183, 46, 40, 0.3)`，不使用浏览器默认蓝色。
- 强调左侧条（如藏品说明卡）：`border-left: 4px solid var(--red)`。

## 6. 交互状态规范

### 6.1 悬停（Hover）

| 组件 | 悬停行为 |
|---|---|
| 藏品卡片 | 图片轻微放大 `scale(1.025)`，260ms ease |
| 题材特写块 | 题名文字变为 `--red` |
| 普通文字链接 | 颜色变为 `--red`，不加下划线 |
| 图标按钮 | 背景变 `#fff`，边框变 `var(--ink)` |
| 主题索引行 | 整行文字变 `--red` |
| 页脚链接 | 变为金色 `#e0b54e` |

悬停动画时长不超过 260ms；优先使用 `transform` 和 `opacity`，避免改变 `width`/`height`/`padding`。

### 6.2 焦点（Focus）

- 所有可交互元素必须有可见焦点环。
- 使用 `:focus-visible` 而非 `:focus`，避免鼠标点击时出现焦点环干扰视觉。
- 焦点环颜色使用 `--red` 的低不透明度版本，与品牌色保持一致。

### 6.3 激活（Active）

| 组件 | 激活样式 |
|---|---|
| 主题标签按钮 | 背景变 `var(--ink)`，文字变 `#fff` |
| 导航链接 | 底部出现 3px 高 `--red` 条线，文字加粗 |
| 视图切换按钮（网格/列表） | 背景变 `var(--ink)`，图标变 `#fff` |

### 6.4 加载与空状态

- **加载中**：使用静态骨架屏（灰色矩形占位），不使用旋转加载图标。
- **图片加载失败**：显示中性占位块（`--line` 色边框 + 缺省图标），不显示破碎图标。
- **搜索无结果**：展示搜索图标 + "没有找到对应藏品" + 操作提示，不显示空白。

## 7. 动效原则

### 7.1 应使用动效的场景

| 场景 | 参数 |
|---|---|
| 卡片图片悬停放大 | `transform 260ms ease` |
| 图标按钮 hover 背景/边框 | `border-color 160ms ease, background 160ms ease` |
| 模态框打开（移动端） | 从底部滑入 `translateY(100%) → 0`，`240ms ease-out` |
| 模态框关闭 | 淡出 `opacity 1 → 0`，`180ms ease-in` |
| 页内平滑滚动 | `scroll-behavior: smooth` |

### 7.2 不应使用动效的场景

- 筛选结果变化（列表项目不需要进场动画，避免感知迟滞）。
- 页面路由切换（保持即时响应）。
- 数字统计数值（不做数字滚动特效）。

### 7.3 减弱动效（Reduced Motion）

当用户偏好 `prefers-reduced-motion: reduce` 时：

```css
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  * { transition: none !important; animation: none !important; }
}
```

## 8. 图片处理规范

### 8.1 宽高比

| 场景 | 比例 | 说明 |
|---|---|---|
| 网格卡片 | 4 / 3 | 通用，防止加载时布局跳动 |
| 精选大卡（首位） | 2 / 1 | 桌面；移动端回退到 4 / 3 |
| 列表行缩略图 | 16 / 9 | 桌面；移动端 1 / 1 |
| 题材特写 | 4 / 5（竖向） | 桌面；移动端 1 / 1 |
| 英雄图 | 高度由容器控制 | `object-fit: cover`，不设固定比例 |

### 8.2 加载策略

- 英雄图：`loading="eager"` + `fetchpriority="high"`，避免 LCP 被延迟。
- 其余图片：`loading="lazy"`，减少初始加载量。
- 图片区域预设固定宽高比，防止加载过程中的布局位移（CLS）。

### 8.3 图片呈现

- 卡片内使用 `object-fit: contain`（完整展示作品，不裁切，因年画比例不统一）。
- 题材特写使用 `object-fit: cover`（构图可接受裁切，追求视觉均衡）。
- 图片背景统一使用 `#fff`，避免透明通道导致的颜色渗漏。

## 9. 组件规范速查

### 9.1 按钮层级

| 层级 | 样式 | 典型用途 |
|---|---|---|
| 主操作 | 实心 `--red` 背景，白色文字，2px 圆角 | 浏览馆藏、首要 CTA |
| 次操作 | 透明底，`--ink` 边框，黑色文字 | 通用操作 |
| 文字操作 | 无背景无边框，底部 1px 细线 | 展品入口、次要链接 |
| 图标按钮 | 40×40 正方形，1px `--line` 边框 | 工具栏、搜索、菜单 |

### 9.2 表单控件

- 高度统一 46px，圆角 2px。
- 焦点时：边框变 `var(--ink)` + 红色浅 outline。
- 搜索框内嵌清除按钮（32×32）。
- `select` 保持原生控件，不自定义下拉样式。

### 9.3 标签与分类按钮

- 高度 70px（桌面）/ 60px（移动）。
- 激活态：背景 `var(--ink)`，文字 `#fff`。
- 非激活：文字 `var(--muted)`，悬停时颜色加深。
- 数量角标：字号 10px，上标位置，`var(--muted)` 色。

### 9.4 藏品弹层

| 属性 | 桌面 | 移动 |
|---|---|---|
| 布局 | 左右双栏（图像 + 说明） | 全宽底栏弹出，竖向滚动 |
| 尺寸 | 最大 1320×860px | 全宽，94svh 高 |
| 工具栏 | 固定在顶部 | `position: sticky; top: 0` |
| 关闭方式 | 关闭按钮 + 点击遮罩 + Esc 键 | 同上 + 向下滑动 |
| 翻页方式 | 工具栏按钮 + 键盘方向键 | 工具栏按钮 + 左右滑动手势 |

## 10. 无障碍基线

- 所有图标按钮必须提供 `aria-label`。
- 颜色对比度目标：正文 ≥ 4.5:1（WCAG AA），大文字 ≥ 3:1。
- 弹层使用 `role="dialog"` + `aria-modal="true"` + `aria-labelledby`。
- 弹层开启时焦点移入，关闭时焦点回到触发元素。
- 图片提供有意义的 `alt` 文字；纯装饰元素使用 `aria-hidden="true"`。
- 导航区域使用 `<nav>` + `aria-label` 区分不同导航块。
- 主题标签组使用 `role="tablist"` + `role="tab"` + `aria-selected`。

## 11. 设计决策记录

| 编号 | 决策 | 理由 |
|---|---|---|
| D1 | 宋体只用于展示层，不用于 UI 操作文字 | 小字号下可读性差，与交互类文字气质不符 |
| D2 | 组件圆角上限 2px | 模仿图录和展陈系统的印刷感，避免"软糖"效果 |
| D3 | 不使用彩色渐变 | 年画原作色彩已足够丰富，界面渐变会与作品产生视觉冲突 |
| D4 | 卡片图片使用 `object-fit: contain` | 年画比例不统一，`contain` 完整显示作品，不裁切 |
| D5 | 弹层而非独立路由（当前阶段） | 原型阶段交互成本低；P1 阶段补充独立 URL |
| D6 | 强调色以朱红为主，绿和金作辅助 | 保持视觉焦点集中，避免多色竞争 |
| D7 | `select` 使用原生控件 | 减少维护成本，原生控件在移动端体验更好 |
| D8 | 图片背景设为白色 | 避免深色 `--paper` 背景使浅色年画边缘模糊 |
