# Desktop 开屏动画重设计方案

> 方案名称：平阳入画 · 年画长卷
> 文档状态：Implemented & Verified
> 整理日期：2026-07-24
> 参考素材：`docs/1192927823.mp4`
> 实现范围：`desktop/`，H5 与小程序不调整

## 1. 目标与边界

本次重设计参考视频的叙事方法，不直接播放、嵌入或逐帧复刻视频。需要提取并重新组织的设计语言是：

- 灰度品牌框架与局部彩色内容形成强烈对比。
- 通过不规则蒙版打开一个文化世界，而不是直接淡入图片。
- 用横向长卷和视差运动串联多个地域文化片段。
- 内容在结尾收回为图册，再完成品牌落版。
- 动画既承担品牌开场，也自然过渡到可操作的馆藏首页。

新动画必须完全使用项目自己的藏品图片、标题和品牌文字，不使用参考视频中的山西地图、建筑、插画、刊物封面、标识或其他版权素材。

## 2. 设计概念

### 2.1 核心命题

**平阳入画 · 一版见天地**

将屏幕视为一张尚未着色的宣纸，将中央不规则窗口视为刚刚揭开的木版印痕。彩色年画从印痕中显现，随后展开成横向长卷，依次经过戏曲、故事、门神与吉祥题材，最后收束为三册数字藏品图录并落下“平阳木版年画 · 数字馆藏”品牌名。

### 2.2 视觉原则

- **真实藏品优先**：画面主体使用 `desktop/public/images/` 中的年画，不制作仿年画插图。
- **横屏重新构图**：参考视频是 720 × 1280 竖屏；Desktop 采用全屏 16:10 / 16:9 长卷，不直接拉伸竖屏构图。
- **平面印刷感**：使用灰纸、墨黑、朱红、藤黄、石青、草绿等平涂色，不使用光效渐变和装饰光球。
- **克制文字**：只显示品牌、题材和作品名，不显示功能说明、操作提示或营销文案。
- **动作有来源**：蒙版对应揭版，色条对应套色，横移对应展卷，图册对应数字归档。

## 3. 分镜与时间轴

目标总时长约 10 秒，比参考视频的 31 秒更适合应用启动。

| 时间 | 画面 | GSAP 动作 |
|---|---|---|
| 0.0–0.8s | 暖灰纸面，大号“平阳 / 年画”墨色底字，中央仅见窄幅彩色印痕 | 底字淡入；印章轻落；套色色标依次出现 |
| 0.5–1.7s | 不规则印版窗口从中央展开，第一段戏曲年画显现 | `clip-path` 从窄幅多边形扩展到全屏；色条从上至下扫过 |
| 1.7–4.0s | 第一幕“戏曲”，真实藏品以前中后景构成舞台 | 图片错位入场；前景与背景采用不同位移形成纸面视差 |
| 3.6–6.1s | 长卷向左推进到第二幕“民间故事” | 整体 track 横移一个视口；局部题签和印色块交错进入 |
| 5.8–7.6s | 长卷推进到第三幕“门神守望”，成对门神成为视觉高潮 | track 再横移一个视口；左右门神从画面边缘合拢但不关门 |
| 7.4–8.4s | 彩色长卷收回中央印版窗口 | 全屏蒙版缩回竖向不规则窗口；背景恢复暖灰 |
| 8.1–9.2s | 三册数字图录从窗口中展开并形成前后层次 | 图册由中心向左右错位展开，轻微旋转和纵深缩放 |
| 9.0–10.5s | “平阳木版年画 / 数字馆藏”品牌落版，随后进入首页 | 品牌名逐行出现；整体淡出并释放页面滚动 |

## 4. 藏品选图

动画只选择构图清楚、色彩差异明显的作品，并控制首屏请求数量：

| 段落 | 作品 | 用途 |
|---|---|---|
| 戏曲 | `py-014 水漫金山`、`py-005 西厢记`、`py-016 黄鹤楼` | 水势、人物和舞台层次 |
| 故事 | `py-030 踏雪寻梅`、`py-038 渭水河`、`py-095 马莲如意` | 文人、叙事和吉祥纹样的过渡 |
| 门神 | `py-099 秦琼敬德` 双幅、`py-089 禄门神` | 成对构图与终段视觉高潮 |
| 图录 | 从三段各取一件代表作品 | 形成数字藏品册落版 |

图片保持原始比例，以 `object-fit: contain` 或明确裁切窗口展示，不拉伸、不重新编码。

## 5. 技术结构

### 5.1 组件拆分

```text
desktop/src/opening/
├── openingIntroSession.js             会话播放、强制重播和完成标记
├── OpeningIntroPanorama.jsx           新“年画长卷”组件
├── opening-intro-panorama.css          新动画独立样式
├── OpeningIntroDoorBackup.jsx         旧“门扉长廊”完整备份
└── opening-intro-door-backup.css       旧动画独立样式备份
```

旧动画保留为可恢复组件，但不参与当前应用构建。恢复时只需将 `App.jsx` 的开屏 import 从 `OpeningIntroPanorama` 切换到 `OpeningIntroDoorBackup`。

### 5.2 GSAP 实现

- 使用一个主 timeline 管理完整分镜，不创建相互竞争的独立计时器。
- 使用 `brand`、`reveal`、`panoramaTwo`、`panoramaThree`、`closePanorama`、`folios`、`finale`、`exit` 八个绝对时间标签，将自然播放时长固定为 10.45 秒。
- 使用 `gsap.context()` 将选择器和动画限定在组件根节点，卸载时统一 `revert()`。
- 横向长卷使用 `xPercent` 移动三段固定视口，避免依赖运行时像素计算。
- 开合使用 CSS `clip-path: polygon(...)`，不使用 Canvas 或视频纹理。
- 蒙版、色条、藏品入场和前一幕退场交叠执行，横卷与收束统一使用 `sine.inOut`，避免状态瞬间切换。
- 背景纸形持续缓慢漂移，藏品使用轻微缩放和不同位移速度形成纸面视差；全部只使用 `transform` 与 `opacity`，避免触发布局重排。
- 跳过时 `kill()` timeline，并以 0.3 秒收尾淡出。

## 6. 行为契约

以下现有能力必须保留：

- 默认每个会话播放一次。
- `?intro=1` 强制重播。
- 页面 reload 可重播，应用内部切换不重播。
- 右上角图标可跳过。
- 跳过或自然结束都必须恢复 `body` 滚动。
- `prefers-reduced-motion: reduce` 时不挂载开屏。
- 开屏开始时继续触发 Desktop BGM；浏览器拒绝自动播放时不阻塞动画。

## 7. 响应式与性能

- 主要验收视口：1440 × 900、1280 × 800、1024 × 700。
- 固定格式元素使用明确宽高、`aspect-ratio` 和 `overflow: hidden`，动画期间不得引发布局跳动。
- 新开屏最多同时加载 9 张现有 WebP，不增加新的位图资产。
- 所有动画元素设置 `pointer-events: none`，只有跳过按钮可交互。
- 不使用滤镜模糊、大面积实时阴影或逐帧 JS 绘制。

## 8. 验收标准

### 视觉

- 1.2 秒截图能够看见灰度品牌框架和正在展开的彩色印版窗口。
- 中段截图能够识别至少两个真实年画主体，不是抽象色块或空白画面。
- 最终落版文字在 1024 × 700 至 1440 × 900 范围内不溢出、不遮挡。
- 动画结束后首页无闪白、无残留蒙版、无横向滚动条。

### 交互

- 跳过按钮在动画任意阶段可用，并在 0.5 秒内进入首页。
- 同一会话再次访问不自动重播；`?intro=1` 可以重播。
- reduced-motion 环境直接进入首页。

### 工程

- `npm run build` 通过。
- `npm run test:ui` 通过并生成最新开屏截图。
- 浏览器控制台无错误，静态资源无 4xx/5xx。
- `git diff --check` 通过。

## 9. 实施顺序

1. 抽离并保存旧门扉组件及样式。
2. 建立共享会话控制模块。
3. 实现新横向长卷 DOM、独立样式和 GSAP timeline。
4. 将 `App.jsx` 切换到新组件，保留 BGM 回调。
5. 扩展 Playwright，在开场、中段和落版分别截图并校验。
6. 完成多视口、跳过、会话、reduced-motion 和构建验收。

## 10. 实施结果

本方案已在 `desktop/` 完成实现，参考视频只用于提炼叙事节奏和转场语言，没有播放、嵌入或复用视频画面。当前应用使用 `OpeningIntroPanorama.jsx`，旧门扉开屏已完整保存为 `OpeningIntroDoorBackup.jsx` 及其独立样式，可通过替换 `App.jsx` 中的组件 import 恢复。

实际实现包含暖灰品牌框架、不规则印版揭幕、六色套色扫描、三幕横向年画长卷、印版收束、三册图录展开和最终品牌落版。主时间轴为 10.45 秒；各幕使用交叠入场、缓慢背景漂移和前后景视差保持连续运动。GSAP 时间轴与组件生命周期已隔离，藏品数据加载不会重启动画。

2026-07-24 验收结果：

- `npm run build` 通过。
- `npm run test:ui` 通过。
- 浏览器观测自然播放约 10.8 秒，自动验收范围为 10–11.3 秒。
- 1440 × 900、1280 × 800、1024 × 700 均无横向溢出或画面重叠。
- 跳过在 500ms 内完成；同一会话不自动重播；`?intro=1` 可强制重播。
- `prefers-reduced-motion: reduce` 时开屏不挂载。
- 浏览器控制台无错误，静态资源无 4xx/5xx。
- `git diff --check` 通过。
