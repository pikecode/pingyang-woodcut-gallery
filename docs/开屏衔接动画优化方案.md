# 开屏衔接动画优化方案

日期：2026-08-01

## 问题诊断

### 问题 1：桥接层遮住 GSAP 前 1.34s（最严重）

当前架构：

```
video 结束
→ phase = "outro"
→ <OpeningIntroPanorama> 渲染，GSAP 时间轴从 0s 开始运行
→ <div.opening-video-bridge> z-index:1200 完全遮住 panorama
→ CSS animation 1.34s 淡出桥接层
→ 用户才能看到 GSAP
```

GSAP 前 1.34s 的印版序列（ink-art-wrap 揭示、ink-pressure 扫过）用户完全看不到，时间浪费，并造成 GSAP 从中途"突然出现"的感觉。

### 问题 2：桥接层（CSS）与 GSAP 不协调

桥接层是独立的 CSS animation，GSAP 时间轴对它毫不知情。两者无法真正协调节拍，只能依靠时长接近来掩盖问题。

### 问题 3：handoff CSS 与 bridge 时长不同步

- bridge 动画：1.34s
- `.is-video-handoff` 的 `panorama-video-handoff-shadow/wash`：1.45s

差了 110ms，视觉上有轻微接缝。

### 问题 4：`handoffFromVideo` 只改 CSS class，不影响 GSAP 行为

两种进入场景（独立播放 vs 接视频）的 GSAP 时间轴完全相同，没有根据视频衔接的情绪做任何适配。

---

## 优化目标

1. 消除桥接层对 GSAP 的遮挡——让 GSAP 始终可见
2. 将衔接逻辑归入 GSAP 时间轴统一控制
3. 视觉上：视频末帧图像作为 GSAP 第一帧底层，由 GSAP 控制其淡出，自然揭开宣纸纸面

---

## 方案设计

### 核心思路：用 GSAP 控制的内嵌 veil 替代外部桥接层

在 `OpeningIntroPanorama` 组件内部，条件渲染一个 `.panorama-handoff-veil` 层：

- 包含视频末帧图像（`opening-guardian-ai-end.jpg`）
- 初始 `opacity: 1`，z-index 高于所有 panorama 内容
- GSAP 时间轴在 `paper`（0s）标签处开始将它从 1 淡出至 0，用时 0.88s

效果：

```
GSAP 时间轴启动（0s）
├── veil（末帧图像）opacity 1 → 0，0.88s
└── ink-art-wrap opacity 0 → 1，0.46s（同时运行，在 veil 下方渐显）

0.88s：veil 完全透明，ink-art-wrap 已进入动画状态
→ 后续时间轴正常推进
```

### 关键改进

| 维度 | 旧方案 | 新方案 |
|---|---|---|
| 衔接层归属 | 外部独立 CSS | GSAP 时间轴内部 |
| GSAP 被遮挡时间 | 1.34s | 0（veil 是 GSAP 内部层） |
| 时长同步 | 两处手动对齐 | 单处 GSAP 控制 |
| 视频末帧延续 | 桥接层 CSS 图像 | GSAP veil 图像，可精确控制 |
| 跳过行为 | GSAP kill + opacity 0 | 不变，veil 随 GSAP kill 一起停止 |

---

## 实施步骤

### Step 1：`OpeningIntroVideo.jsx`

- 删除 `outro` phase 中的 `<div className="opening-video-bridge">` 及所有子元素
- 向 `OpeningIntroPanorama` 传入 `handoffFrameSrc={END_FRAME_SOURCE}` prop

### Step 2：`opening-intro-video.css`

- 删除所有 `.opening-video-bridge*` 规则
- 删除 `@keyframes opening-video-bridge-*`

### Step 3：`OpeningIntroPanorama.jsx`

- 增加 `handoffFrameSrc` prop
- JSX 中条件渲染 `.panorama-handoff-veil`（仅 `handoffFromVideo` 时）
- GSAP `initialContext` 中：`handoffFromVideo` 时 `gsap.set(".panorama-handoff-veil", { opacity: 1 })`
- `timelineContext` 中：`handoffFromVideo` 时在 `paper` 标签处加入 veil 淡出动画

### Step 4：`opening-intro-panorama.css`

- 删除 `.panorama-intro.is-video-handoff` 及相关 `@keyframes`
- 新增 `.panorama-handoff-veil` 样式
